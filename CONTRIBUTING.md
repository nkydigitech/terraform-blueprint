# Contributing to Terraform Blueprint

First off, thank you for considering contributing to **Terraform Blueprint**! It’s people like you who make it a great learning resource for everyone.

## How Can I Contribute?

### Reporting Bugs
- Check the issue tracker to see if the bug has already been reported.
- If not, open a new issue with a clear title and description.

### Suggesting Enhancements
- We are always looking to improve the curriculum! If you have a better way to explain a concept or a more relatable lab idea, let us know.

### Pull Requests
1. Fork the repo and create your branch from `main`.
2. If you've added a new lab, ensure it follows the "Local-First" philosophy.
3. Update the documentation to reflect any changes.
4. Issue a PR!

## Style Guide
- Keep explanations simple and jargon-free where possible.
- Use emojis to make the READMEs engaging.
- Ensure all Terraform code follows `terraform fmt`.

Happy Coding! 🚀
